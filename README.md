# FOCUS
FOCUS is a fullscreen study timer for Windows. It helps you focus during study sessions and tracks your cumulative study and break time.

## Download and use
1. Download `FOCUS.exe` from the project's GitHub Releases page.
2. Run the executable.
3. Set the study and break durations, then select **START** or press **Enter**.
4. During a break, select **END BREAK** to resume studying.

Your timer statistics are saved locally in `focus_data.json`.

## Run from source
Run the app with Python. If any dependencies are missing, FOCUS installs them from `requirements.txt` automatically. An internet connection and `pip` are required for the first installation.

```bash
python FOCUS.py
```
